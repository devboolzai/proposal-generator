# הוראות הוספת פונט Fb Gandalf

שים את קבצי הפונט כאן:

1. מצא את הקובץ `FbGandalf-Regular.ttf` (או .woff2) במחשב שלך
   - בדרך כלל נמצא ב: `C:\Windows\Fonts\`
   - חפש קבצים שמתחילים ב- `FbGandalf` או `Fb Gandalf`

2. העתק את הקבצים לתיקייה הזו:
   - FbGandalf-Regular.ttf (או .woff2)
   - FbGandalf-Bold.ttf (או .woff2) — אם יש לך

3. אם שם הקובץ שונה, עדכן את הנתיב ב:
   - `src/fonts.css` (שורות ה-src)
